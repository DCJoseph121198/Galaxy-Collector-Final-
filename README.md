# Galaxy Collector

## Project Option
Simple Browser Game

## Project Description
Galaxy Collector is a space-themed browser game where the player controls a spaceship and collects asteroids while avoiding dangerous obstacles. The goal is to survive as long as possible and earn the highest score.

## Theme Interpretation
The project follows the Space theme by using a galaxy background, asteroids, a spaceship, space sound effects, and gameplay that takes place in outer space.

## Intended User or Player
The game is designed for anyone who enjoys simple arcade-style browser games, especially students and casual players.

## User or Player Goal
The player's goal is to collect as many asteroids as possible while avoiding obstacles and achieving the highest score.

## Main Features
- Start button to begin the game
- Player movement
- Collectible asteroids
- Score counter
- Sound effects
- Game Over screen
- Restart option

## JavaScript Features
JavaScript controls the gameplay by moving objects, detecting collisions, updating the score, playing sound effects, and displaying the Game Over screen.

## Responsive Design
The game adjusts to different screen sizes using responsive CSS so it can be played on desktop and mobile devices.

## User Testing
The game was tested by multiple users to verify that the controls worked correctly, the score updated properly, and the game could be restarted without errors. Feedback showed the game was easy to understand but needed a few improvements.
